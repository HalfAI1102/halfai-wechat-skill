# 稿件语法与组件

稿件是一个 Markdown 文件：开头 front matter，下面是正文。每个组件都对应 HalfAI 视频包装库里的一个模板（T01–T17），视觉和视频保持一致。完整示例见 `examples/demo/article.md`。

## Front matter

```yaml
---
title: 上下文一百万 token，      # 标题第一行（白字，说事实），通常以逗号结尾
title2: 到底能干什么？            # 标题第二行（灰字，给观点）
eyebrow: EP.27 · AI 实测          # 片头卡上方绿色等宽小字
bar_left: EP.27                   # 片头卡进度条左边的小字（默认取 eyebrow 第一段）
date: 2026.10                     # 片头卡进度条右边
digest: 一句话摘要，填公众号后台   # 预览页显示，方便复制
wechat_title: 可选，公众号标题      # 默认 = title + title2
slug: 可选，输出文件名前缀          # 默认 = 稿件文件名
item_label: SKILL                 # `##` 条目的编号前缀，如 SKILL 01 / 08（默认 NO.）
sub_label: TYPE                   # `###` 小分类的编号前缀（默认 TYPE）
author: HalfAI                    # 作者条（默认 HalfAI）
author_desc: AI 工具实测 · 每周更新
ending: 今天就到这。               # 片尾两行，默认就是这两句
ending2: 剩下的一半，下期讲。
next: 下一期标题                   # 可选：片尾「下一期」卡
prev: 往期标题                     # 可选：片尾「往期」卡
preview_note: 预览页左侧说明文字    # 可选
header: no                        # 可选：不要片头卡和作者条
brand_banner: yes                 # 可选：作者条后插入像素风品牌横幅，默认 no；900×383 GIF 自动内嵌
footer: no                        # 可选：不要片尾
---
```

## 正文

| 写法 | 效果 |
|---|---|
| 普通段落 | 正文段落；**全文第一段**自动用大一号的导语样式。相邻行会合并成一段，空行分段 |
| `**关键词**` | 深绿加粗（深色卡里是白色加粗） |
| `==重点句==` | 绿色下划线（提示词卡里是白字绿下划线） |
| `` `代码` `` | 等宽灰底行内代码 |
| `[文字](网址)` | 公众号正文不能放外链，渲染成绿色文字 +（网址） |
| `# 标题 \| 副标题` | 章节（T10）：绿色方块大号编号 + CHAPTER 01，自动编号 |
| `## 名称 \| 副行 \| 右侧标签` | 条目（清单文的每一项）：`SKILL 01 / 08` 自动编号和总数，副行是等宽小字（如 slug） |
| `### 名称 \| 右侧小字` | 小分类：`TYPE 01 名称 4 种`，适合一章里再分组 |
| `![说明](images/x.gif "图注")` | 内嵌图片 + 灰色居中图注；文件不存在时放「图位」占位。扩展名可省略 |
| `---` | 分隔符：空 → 半 → 满 三个圆 |
| 以 `<` 开头的行 | 原样输出的 HTML（必须是内联样式） |

## 块组件 `:::名称 参数` … `:::`

```
:::list 合计 | 59 种          → 白底编号清单（参数可选：最后加一行粗线合计）
- 左边名称 | 右边绿色说明
:::

:::steps 3                    → 步骤 / 工作流（T05/T11），参数 = 高亮第几步（默认最后一步）
- 步骤标题 | 下面一行灰色说明
:::

:::prompt 直接复制到 WorkBuddy  → 提示词卡（T04），墨黑底，参数是右上角备注
提示词正文，用 ==变量== 标出可替换部分
:::

:::note 先备份原文件            → 注意事项（T16），白底感叹号卡，参数是标题
正文，可以多行
:::

:::quote 官方公告 | 2026.10.08  → 资讯引用（T08）
被引用的原文
解读：HalfAI 的一句话解读（可选，以「解读：」开头）
:::

:::number 放大倍数              → 大数字（T07）
5.2×                            第 1 行数字（结尾的 × % 倍 + 自动变绿）
放大到 5 倍，文字边缘依然清晰       第 2 行说明
示例数据 · 以实际测试为准          第 3 行脚注（可选）
:::

:::table 示例价格 · 以官网为准    → 方案对比表（T09），参数是右下脚注
| | 免费版 | 专业版* | 团队版 |   表头带 * 的列是推荐列，整列浅绿高亮
|---|---|---|---|
| 月费 | ¥0 | ¥68 | ¥198 |
:::

:::score 值不值得用？ | 4.5       → 评分卡（T14），总分可省略（自动取平均）
- 效果 | 字幕准确率很高 | 4.5      每行：维度 | 说明 | 分数（0–5，可打半分）
:::

:::summary 一句话总结           → 结论金句（T15），两行：白字 + 灰字
能读完 300 页，
不等于能读懂 300 页。
:::

:::card GITHUB · 免费开源        → 墨黑信息卡（带 HA 标志），放链接、安装命令等
https://github.com/xxx/yyy
:::

:::html                         → 原样输出（自己写的内联样式 HTML）
<section style="...">...</section>
:::
```

## 典型文章骨架

- **工具实测**：导语 → `:::list` 速览 → `# 它是什么` → `# 怎么用`（`:::steps` + `:::prompt` + 截图）→ `# 和对手比`（`:::table` / `:::number`）→ `:::score` → `---` → `:::summary` → 结尾一段。
- **清单文（N 个必装…）**：导语 → `:::list` 列出 N 项 → `# 先搞懂…` → `# N 个…`，每项一个 `##` + 段落 + `:::prompt` + 图 → `# 踩过的坑`（`:::list`）→ `---` → 结尾一段。
- **开源项目介绍**：导语 → 图鉴图 → `# 一览`（`:::list` 合计 + 各 `###` 小分类配动图）→ `# 我的感受` → `# 怎么安装`（`:::card` 仓库地址 + `:::steps` 命令 + `:::prompt` 示例 + `:::note` 前置条件）。
