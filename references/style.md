# HalfAI 视觉与写作规范（公众号版）

规范来源是视频包装库「HalfAI 包装模板库」（17 个模板 T01–T17）。公众号排版沿用同一套：墨黑 / 纸白 / Half 绿 / 半圆母题。

## 颜色（只有一种强调色）

| 名称 | 色值 | 用在哪 |
|---|---|---|
| Half 绿 | `#2BE08C` | 深色底上的强调：kicker、下划线、进度条、章节编号方块 |
| 深绿 | `#0F6B44` | 纸白底上的强调：加粗关键词、kicker、半圆图标 |
| 墨黑 | `#090A09` | 品牌动图底色、提示词卡、片尾、标题字 |
| 白 | `#F2F3F1` | 深色底上的主文字、HA 标志 |
| 灰 | `#7D837F` | 标题第二行（观点）、图注、注释 |
| 线 | `#2A2E2B` | 深色卡上的线 |
| 纸白 | `#F2F1EC` | 文章底色 |
| 正文 | `#1E2320` / 次级 `#59605B` | 正文字 |
| 浅线 / 填充 | `#DCDDD7` / `#E7E6E0` | 分隔线、占位、行内代码底 |
| 推荐列底 | `#E4F2EA` | 对比表推荐列 |

不要引入第二种强调色（蓝、紫、橙都不行）。

## 字体与字号

- 系统字体栈：`-apple-system, PingFang SC, Noto Sans SC, Hiragino Sans GB, Microsoft YaHei`。公众号不能加载网络字体。
- 等宽：`Menlo, Consolas, SF Mono`，用于 kicker（`CHAPTER 01`、`PROMPT`）、编号、日期、网址。kicker 11px、字距 1.5px、大写英文。
- 正文 15px / 行高 1.85 / 字距 0.4px；导语 16px；章节标题 21px 900；片头标题 26px 900。

## 标志

- **HA 标志**（`assets/ha_path.txt` 里的 SVG path，viewBox `0 0 344.5 347.8`）在品牌片头 GIF 以及片尾使用，**永远白色**、放在墨黑底上；旧片头卡和作者条已取消。不要用绿色，不要用半圆代替它。
- **半圆**是装饰母题：小图标（条目、引用、提示词卡）、分隔符（空 → 半 → 满）、评分（半圆 = 半分）。

## 写作规则

- 标题两行供公众号标题与预览页使用，正文开头只显示像素 GIF，不再生成带标题的片头卡。例：「WorkBuddy 必装的 8 个技能，」+「装完才算真的能干活」。
- 导语一句事实加一句问题，只抛一个点。
- 每段只讲一个点，三到五行换段；每段最多一个加粗关键词。
- 不用感叹号；小标题 ≤ 10 个字。
- 写实测：耗时、花费（额度/钱）、真实结果和翻车点。截图、动图要来自真实运行，图注写清楚图里发生了什么。
- 口播稿转文章时只顺句子，保留用户的语气和观点。
- 片尾固定：「今天就到这。」「剩下的一半，下期讲。」+ 关注 HalfAI。

## 品牌像素动图

- `assets/halfai-pixel-banner.gif` 是用户确认的 900×383 公众号横幅，黑色底、绿色强调，画面含像素人物、猫咪和完整标语：「让 AI 成为你的下限，你来决定上限。」。
- 左上角 HA 使用用户原始白色标志，保持清晰；动图是确定版素材，不重绘 Logo，不改变原排版与人物。
- **所有文章都默认在正文最开头插入该动图**，旧片头卡和作者条不再出现，无需配置；排版器跳过正文中对相同 GIF 的重复引用。
